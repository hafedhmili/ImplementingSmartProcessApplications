### What to do to get the program to work


1.  Connect to Azure IoT
2.  Go to IoT Hub
3.  Select the IoT hub instance that I created for the project. It is called "IOT-hub-for-heart-monitors"
4.  Under "Device Management" on the left hand side menu, select "Devices"
5.  Identofy the device that simulates the heart monitor driver. In the test program it is called "heart-monitor-PID-04048"
6.  Regenerate its primary and secondary keys
7.  Copy the new refreshed connection string and use it in the test program
8.  You can run the test that connects to the IoT hub ()
9.  If that one works, you can try the more advanced methods.
